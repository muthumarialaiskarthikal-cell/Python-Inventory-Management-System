
# Python Inventory Management System

## Project Description
The Inventory Management System is a Python-based
application used to manage product details and stock
quantities easily.

It uses SQLite database to store product information.

## Features
- Add new products
- View all products
- Search products by ID
- Update product quantity
- Delete products
- Store data permanently using SQLite
- Error handling and logging

## Technologies Used
- Python
- SQLite Database
- GitHub

## Project Structure

Python-Inventory-Management-System/
- app.py
- database.py
- requirements.txt
- README.md

## Database Schema

Table Name: products

| Column Name | Data Type |
|-------------|-----------|
| product_id | TEXT (Primary Key) |
| product_name | TEXT |
| quantity | INTEGER |

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python app.py

## Requirements
Python 3.x

No external packages are required.
